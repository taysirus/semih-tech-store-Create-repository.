
KURULUM
1) Dosyayı Vercel'e yükleyin (New Project -> Import -> Upload -> bu klasörü ZIP olarak yükleyin)
2) Build komutu: next build, Start komutu: next start (Vercel otomatik algılar)
3) Alan adınızı Vercel'de bağlayın.
4) Admin'e girmek için sağ üstte 'Yönetici Girişi' butonuna tıklayın.

ÖDEME / GÖRSEL
- Cloudinary: Admin panelde 'Cloud name' ve 'Unsigned preset' girerek görselleri yükleyin.
- iyzico: Vercel Env'e IYZI_API_KEY, IYZI_SECRET_KEY, IYZI_BASE_URL girerseniz gerçek yönlendirme akışına geçebilirsiniz.
